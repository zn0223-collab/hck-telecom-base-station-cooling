# Telecom Base Station Cabinet Air Conditioner

Outdoor cooling for BTS / telecom enclosures (BBU, RRU, power and transmission cabinets).

## Why
- Outdoor cabinets house heat-generating active equipment; a sealed AC maintains a safe temperature across an ambient range of −40 … +55 °C.
- IP55 plus corrosion protection suit rooftop, rural and coastal sites.
- Remote monitoring over RS485 / Modbus reduces site visits.

## HCK solution highlights
- Cooling capacity 2000–7500 W
- IP55 enclosure, operating range −40 … +55 °C
- R410A, rotary compressor, high-efficiency motor
- Corrosion-protected coil
- RS485 / Modbus monitoring with alarm output
- No US-restricted components; CE-marked; OEM/ODM

## Selection note
Estimate cooling load `Q = Q_internal + U·A·ΔT`. For a typical outdoor telecom cabinet, size from
equipment dissipation at summer peak ambient.
